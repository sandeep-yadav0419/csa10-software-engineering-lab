# Generate the Figma design

The code is prepared; it has not been run in a connected Figma account.

1. Open the Figma desktop editor and create a design file.
2. Use Plugins → Development → New plugin. Create a Figma design plugin
   that runs once. Keep the manifest and plugin ID generated by Figma.
3. Replace that plugin's `code.js` with this folder's `code.js`. No build or
   external package is required. Run it through Plugins → Development.
4. The plugin creates editable frames and clickable button reactions. Select
   the first Home frame and use Present. For experiment 03, present A and B
   separately by selecting each variant's Home frame.
5. Save the Figma file URL and real screenshots after verifying the navigation.

Alternatively, import the SVGs from `screens/` for editable visual assets and
connect their navigation in Prototype mode. The SVG links are for the browser
preview; Figma prototype links are supplied by the plugin, not by SVG import.
