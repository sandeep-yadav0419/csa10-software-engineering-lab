# Library Management Sprint 1

Duration: one week. Set the real start and end dates when starting the sprint in Jira.
The backlog contains five stories and 16 story points. These estimates and the
schedule below are planning examples, not a record of a real team sprint.

Goal: demonstrate a member searching for a book, borrowing it, returning it and
viewing their loan history. Use the ranked backlog order; do not assume story
points are hours. Compare 16 points against the team's actual capacity before starting.

| Day | Planned activity |
| --- | --- |
| 1 | Planning and member login |
| 2 | Catalogue search |
| 3 | Issue workflow |
| 4 | Return workflow and borrowing history |
| 5 | Integration checks, sprint review and retrospective |

Definition of done: acceptance criteria demonstrated, relevant tests pass,
changes reviewed, and the issue contains evidence. Move unfinished stories
back to the backlog when closing the sprint; do not mark them Done to force completion.
